# Luck Git standard

Apply the [SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html)
to Git work in this repository.

## Commit messages

- Write the subject in imperative mood, such as `Add task deletion support`.
- Capitalize the first letter and do not end the subject with a period.
- Prefer subjects of 50 characters or fewer; never exceed 72 characters.
- For non-trivial commits, separate the subject and body with a blank line.
- Wrap the body at 72 characters.
- Explain what changed and why. Do not merely describe implementation steps.
- Split unrelated changes into separate focused commits when practical.

## Branch names

- Use meaningful names in kebab-case, such as `refactor-command-handler`.
- When applicable, prefix an issue number, such as `1234-fix-task-storage`.

Do not commit, amend, push, or rewrite history unless the user explicitly requests it.
